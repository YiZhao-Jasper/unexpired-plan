Reading the evidence

The interactive evidence panel uses the two original Figure 1 frames for each condition. It switches between inspection and outcome; it does not synthesize intermediate robot motion. Original Figures 1 and 2 can be opened as vector images. The result chart and table reproduce the paper's values, including paired uncertainty and the undecided PushT result.

The moving comparison is an original controlled MuJoCo illustration. Its inputs are synthetic, its object attachment is choreographed, and object contact is disabled. The actual monitor controls the monitored arm, using deviation-triggered fallback and persistent demotion. The near-repetition veto is disabled in this illustration. Both clips share the initial state, disturbance, reference schedule, camera, duration, and playback speed. Neither these two trials nor the real-robot excerpts constitute additional benchmark evidence.
